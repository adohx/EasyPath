# Screenshots

The root `README.md` references four images that need to be added here
before they'll render on GitHub:

| File | What to capture |
| --- | --- |
| `search.png` | Search tab with a few results showing (e.g. after searching "library") |
| `explore.png` | Explore tab with a category selected and its result list visible |
| `route_detail.png` | Route detail screen — overview tab, showing the accessibility score bar |
| `my_places.png` | My Places tab with at least one tracked place visible |

Run the app (`flutter run`), navigate to each screen, and take a
screenshot (phone screenshot, or `flutter screenshot` via `flutter run -d
<device>` and pressing `s` in the terminal). Crop/resize isn't required —
GitHub will scale them to fit the table in the README.
